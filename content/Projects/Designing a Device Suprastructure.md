# Implementation 
>The suprastructure described here omits some components that are described in detail in [[Analog Systems]] and [[Digital Systems]].

I implement my device suprastructure in a manner inspired by the Unified Modeling Language (UML) in LucidChart. 

![[Platform-Device Suprastructure.png]]
*Fig 1.* Platform-Device Suprastructure: PC and [Reflectorate](<The Reflectorate.md>).
- On my PC/Laptop I (typically) exclusively use eight apps: Obsidian, default Windows file folders, Ubuntu in WSL, LaTeX, Git/GitHub, LucidChart, Google Sheets, and OneNote. I also use Anki, which is not depicted here.
- [[The Reflectorate]] is a notebook network, specified on the right, that I use to coordinate my reflections.

Each app on my PC/Laptop has a very specific purpose.
- *Obsidian*: I use Obsidian to organize and govern my thoughts, reflect on my experiences, come up with and develop ideas, and manage projects.
- *Windows filesystem*: I use this to organize forms and documents that I download externally. 
- *LaTeX*/*TeXStudio*: I use TexStudio (and occasionally Overleaf) to formally codify summative or reference documents for my priority projects and inquiries. 
- *Ubuntu*: I use Ubuntu within the Windows Subsystem for Linux for coding projects.
- *Git*: I use Git for software project management and publishing/archiving code.
- *Lucid*: I use Lucid to draw visual diagrams
- *master*: I use a Google Sheet called “Project Master” to coordinate my tasks for medical school studying, my other personal projects, and extracurricular/professional engagements. 
- *OneNote*: I find that OneNote is unreasonably effective at helping me internalize core concepts in medicine that are amenable to 2D colorful visuospatial depiction. Examples include the leukocyte activation cascade, the hypothalamic-pituitary-ovarian axis, pelvic anatomy, and most medical management workflow diagrams.
