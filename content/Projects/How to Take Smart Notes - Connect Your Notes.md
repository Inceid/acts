# Make smart connections 
Luhmann used four kinds of links for his slip-box:

## Overview → note 
>This links an overview note to a regular note. 
* For each link in an overview, add a one-sentence summary of the contents of the linked note. 

## Overview → local, physical note clusters 
>This links an overview note to clusters of physical notes.
- Only necessary if you’re working with pen & paper.
- A “geography” of the slip-box’s landmasses of original lines of thought modulo branching events.

## Note → followup
>Links sequences of notes together. 
- Only for linking conceptual sequences of notes together.

## Note → note
>Links two regular notes together. 
- Simply indicate some relevant connection between two notes. 


>“The slip-box is like a well-informed but down-to-earth communication partner who keeps us grounded. If we try to feed it some lofty ideas, it will force us to check first: what is the reference? How does that connect to facts and ideas you already have?" (115)
