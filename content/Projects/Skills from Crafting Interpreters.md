# Skills from Crafting Interpreters

## Paradigms 
1. Disciplined, principled software design 
	- separation of concerns and abstraction
	- hierarchies of modules 
	- memory management 
	- optimization via serialization, encoding, and packing 
2. Metaprogramming to automate generating boilerplate code. 
3. How to structure software & relearn basic design patterns and software architecture best practices; `jlox`
	1. visitor patterns; interfaces & implementations; separation of concerns; recursive descent

## Particulars 
1. How to program in Java (you didn't know how to do it before!); `jlox`
2. How to write a programming language compiler/interpreter in two languages; `jlox`, `clox`

## Metaparadigms 
1. Basic aspects of the structure and design of programming languages; `anno`, `jlox`, `clox`
	1. context-free grammars, ASTs, BNF notation, environment chaining, lexical scope, semantic analysis & closures
2. Applying syngenesis: how to write notes for a programming book, program the code from it, and take notes on the book itself; `anno`
	1. This is actually quite important and has served as an (subconscious/unnoticed) implementation of the Zettelkasten method. I have to take notes *as I am reading*, and often. I have to link my notes together into a knowledge network. 
3. Applying iterative metacognition: how to update `RI`'s Daily notes, Essays, and Perennials to explicitly commentate on my progress and my reflections throughout my progression; `anno`
4. How to persist on a long-term project; `anno`, `jlox`, `clox`
5. How to tune `RI` along the way to optimize its ability to archive and embellish my work on my projects. `anno`, `RI`

## Miscellany
* Basic metaprogramming techniques via writing and extending `GenerateAst.java` as we considered new AST types; `jlox`
- An exercise in [[Practical Foundationalism]]
