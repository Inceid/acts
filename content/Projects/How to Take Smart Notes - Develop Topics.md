# Put connections in a sequence
The slip box is now a pantry of ideas. Let’s say you want to cook up a manuscript. 

To do so, we’ll want to order existing notes into a loose sequence. 
- loose, because imposing a presupposed hierarchy renders the product vulnerable to confirmation bias; 
- sequential, because a disordered set of connections without conceptual connections makes notes scattered.

# Create Overviews
One possible way of organizing the slip-box at top level is with an Index note that links to topic overview notes containing links to references and work within their corresponding topic. 

An index should be structured so that the user spends as little time in it as possible, and as much time within the world of the slip-box itself, navigating notes by connections.

# Emergent Problem Descriptors as Keywords
**Defn.** An **emergent problem descriptor** is a descriptor for a problem under study that does not reduce to special terms within the relevant notes.

>*Example:* **capital allocation problem** is an emergent problem descriptor for a set of notes that don't contain that term in their content. This creates an emergent "name" for a possibly heterogeneous set of notes, for which the label is also *context-specific*. The term describes a concrete problem and is structured to pose questions about the problem.
