# Notation

	\<new sequence\>
(`return`)

# Definition 
An **Interjection** is an interruption in a thought stream which either 
- passes control of the sequence from one speaker to another, or 
- introduces a new topic for discussion. 

Interjections typically `return` control to the prior or default stream.
