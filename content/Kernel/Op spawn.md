# Notation. 
`spawn` *Note spawned*

# Definition. 
**Spawn** creates a new note following a discussion about a particular theme in Daily notes. This behavior is distinguished from ordinary note creation in that the note specifically arises as a result of thoughts displayed in Daily streams. 

# Standard usage.
`spawn` is usually used alongside `graft` to indicate that 1) a preceding thoughtstream led to the creation of the corresponding note and 2) the relevant content of that thoughtstream is pasted into the note. This is denoted as
	`spawn` Note `graft`
