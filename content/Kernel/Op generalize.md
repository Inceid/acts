# Notation. 
*Content to generalize*
`gen` *generalization of that content*

# Definition. 
`generalize` is an operator that generalizes a preceding pattern in closed or iterator form. A closed form describes an expression that can be “opened” to describe any instance in the pattern. An iterator form is a sequence describing the pattern, which may not have any closed form. 

# Implementation. 
The best procedure for generalizaton in any context is the following: 

1. Come up with an example of a pattern. 
2. Come up with a second example of the pattern. Ensure that the first instance connects to the second. 
3. Infer the general pattern and verify any inductive rule.
