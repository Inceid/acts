# Notation 
`graft` *Note to graft content into*

# Definition 
In the context of a running thoughtstream, **grafting** refers to copying a significant amount of the thoughtstream into a currently existing note without modification. 

Usually used within a thoughtstream. Usually applied to existing notes.
