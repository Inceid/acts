# Notation
`invoke` \<`arg`: *Theme from a prior note Invoked Note that is relevant to the current stream.*\>
`echo` \<same as above\>

where `arg` is a note, person, or cue for the invocation.

# Definition
**Invoke** is a command that invokes a theme from a prior note (usually a perennial, essay, or other self-contained note) for usage in a thoughtstream or annotation.
