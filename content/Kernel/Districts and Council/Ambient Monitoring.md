# Definition 
**Ambient monitoring** is a technique to record fluctuations in thought and emotions in real time.

# Implementation 
There are a few ways to implement ambient monitoring: 
1. As a “persistent journaling technique”: any time I think of something or have a fleeting thought, I write it down physically in one of my personal journals. 

2. Ambient monitoring is implemented in [daily notes](<MM.DD.YYYY>) via:
- automatic logging scripts that log changes in `RI`; 
- keeping daily notes in persistent view in a side pane;
- manually logging any events or reflections into them as the day goes by. 

Ambient monitoring is also implemented whenever I invoke a [mobile/ambient kernel](<Ambient Kernel.md>).
