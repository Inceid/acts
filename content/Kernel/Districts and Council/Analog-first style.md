# Definition 
An **analog-first** style is a method of learning whereby the learner applies kinesthetic, hands-on, conrete, “analog” (as opposed to digital, encoded, or abstract) learning and implementation techniques prior to progressing to more abstract implementations. 

>[!example] Example: Compilers
>To implement an OS or compiler, it’s easier to implement a concrete version of code-to-representation transformers such as a music box or calculator.
