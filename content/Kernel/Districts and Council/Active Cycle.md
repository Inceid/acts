>I want to do so, so many things. How am I supposed to do everything at once? 

# Definition 
An **active cycle** or **standard rotation** is a list of tasks or projects that one rapidly cycles between. 

Typically a good cycle has tasks that complement, reinforce, or seamlessly transition into one another.

A **transition system** is a sequential ordering of tasks from an active cycle or a rule set for transitioning between tasks in a given work session.

# In-place transition systems 
An *in-place transition system* is a transition system that one traverses in the same place and at the same time.
