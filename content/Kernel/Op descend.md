# Ancestors 
[[Op seq]]

# Notation. 
```
desc X
    B
X := name of target inquiry 
B := body of descent 
where B :=
- seq1 
...
- seqn
```

# Definition
`descend` or `desc` is a descent into a specific inquiry, question, project, or sustained reflection on a subject. It normally consists of a set of `seq`s. These `seq`s must somehow be related - the user can specify the nature of this relation. 

# Implementation 
A `descent` may consist minimally of a `seq` in prose that instantiates and sustains an inquiry over multiple ideas. 

More concretely, a `descent` that survives selection against other ideas in my cognitive background may progress to a Project, which may yield an [[Annotation]], [Dynamic Essay](<The Dynamic Essay>), or concrete deliverable such as a program.
