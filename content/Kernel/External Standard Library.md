>The goal of all theory is to make the basic elements as simple and few as possible without having to surrender the adequate representation of experience. 
>*Albert Einstein*

# Definition 
The **External Standard Library** is my standard library of literature to draw ideas, inspiration, and long-term knowledge and wisdom from. 

# Purposes
A key purpose of a standard library is to operationalize its knowledge in creative endeavors. 

A second key purpose is to establish continuity of engagement with ideas. Rather than read more and more books/essays/ideas, I find it more helpful to return to the same literature, particularly literature that I struggled with, felt was foundational to my personal and intellectual development, and see as useful for applying to my projects today.

# Implementation
A standard library should be the *smallest* possible library that spans a knowledge space. In other words, a standard library forms an effective *basis* of the knowledge space it intends to describe. 

A standard library should also enable an unspecialized user to gain access to the knowledge spaces it describes. As such, it should include high-quality (and preferably informal) introductory texts.
