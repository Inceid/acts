# Notation. 
`reset(<time period>)`

# Definition. 
A **reset** re-sets RI to a base state after a certain time period has passed. 

The following specify the base states / actions for different time periods:
`reset(week)::`
* clear email. Any actionable items go into Trello. Other items get resolved/archived.
* check calendar for meetings in the upcoming week(s). Action items get put into Trello. Notes, insights, and reflections go into `RI`.
* clear computer Desktop into Fences and folders.
* On Sunday, clear inbox in `RI`.
	* At minimum, *only* do the following for each inbox note: add tags/dates, file them into folders, and connect them under a heading/hub note if a relevant one exists. Do not add any other connections.
