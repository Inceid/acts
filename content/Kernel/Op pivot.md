# Notation
`pivot` *Speaker or element by which to pivot a dialogue or structure*

`pivot X -> Y`
where 
-  `X` is a set of elements to pivot 
-  `Y` is the target of the pivot

# Definition. 
**Pivoting** a structure by an element returns the structure from the perspective/description of that element. 

# Implementation 
The best way to define pivots is by using pivots: 

`pivot` *Linear Algebra*:
>Pivoting `X` by `Y` is analogous to projecting `X` onto the space described by `Y`. 

`pivot` *Computer Science*:
>Pivoting `X` by `Y` is analogous to typecasting `X` to the type specified by `Y`.

`pivot` *Council*:
Suppose the council is in dialogue/session. Then `pivot General` returns [General's](<The Council>) perspective on the dialogue. 
* In the context of multidisciplinary work, `pivot Pol CS` returns a Computer Science perspective or description of the phenomenon under study as described by a political science/philosophy perspective.
