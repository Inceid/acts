# Notation
```
new N : X -> Y := def

N := object category ({operator, notation})
X := previous version of object (optional)
Y := new version of object
def := definition of new object (optional)
```
example:
`new op` `recensio` `:=` `Examine and systematically reassess the past in a constructive and agentic manner.`

# Definition
`new` indicates the explicit declaration of a new kernel operator, rule, or notation form.
