# Notation 
`decisis` \<decision\>

Where \<decision\> is a maxim in Korsgaardian (ACE) form: 
- an Act, 
- a Circumstance, and 
- an End for the act. 

# Definition
A **Decisis** is a decision made according to a formal decision procedure. 

# Preamble 
Decisions can be complicated. In my case, I’ll have to make many important decisions probably for the rest of my life. Not only will I have to choose what kind of doctor I want to become, but I’ll also have to choose the residency program I want to go to, 

It should behoove anyone to take these kinds of decisions with utmost seriousness. 

# Weighted Decision Matrices 
The basic formula of a set of plausible options is a description, a set of pros/benefits, and set of cons/drawbacks/costs. 

Decisions amount to performing a cost-benefit analysis. 

## Establish symmetries of representation 
It’s extremely important that you establish a representation of any decision with multiple options that *has the same data/columns for each decision somehow represented* in the matrix. I call this a **symmetry of representation** for decisions. 

# Incommensurability 
Modern economic interpretations tend to quantify costs on a standardized scale. This standardization scheme may not apply to all options in a decision: certain options may have an overriding value over others. If it is impossible to compare the value of one option to another, we say the two options are **incommensurable**.
