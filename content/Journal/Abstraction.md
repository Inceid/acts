# Definition 
An **abstraction** is a representation of an object that eliminates unnecessary details. 

>A special case of abstraction is the “metafication” or “metamodeling” of something. For example, thinking about thoughts, or “metacognition”, is a metafication of thinking. 

# Significance 
Abstraction is likely the most powerful aspect of human language and thought. If implemented well, it enables both to be effective at accomplishing their intended goals.

# Abstraction Hierarchies 
An *abstraction hierarchy* organizes abstractions into layers that become progressively more “lower-level” or detailed as one progresses down the hierarchy.

# Unwrapping and Rewrapping 
`gen` [[Cognitivization|cog]] and [[Decognitivization|decog]]

Interacting with any object/concept begins with an abstraction, a simplified mental representation of the object/concept. 

Tis initial abstraction is necessarily insufficient to explaining the object fully. 

The point here isn’t to be “right”. All models are wrong, but some of them are useful. We care about using the abstraction to manipulate the object. 

>[!example] Example: Programming
>When we first learn how to program in Scratch, we manipulate data with blocks without paying attention to how the data is actually implemented in the computer. 
>
>Similarly, with Python, we manipulate data with lists, dictionaries, and libraries like `pandas` without understanding how they are implemented by the language at bedrock. 
>
>And we don’t know how the language is actually implemented in the computer (it’s compiled in `C` via `CPython`).

As you learn about things at a more advanced level, you start to “unwrap” the abstractions you were previously taught to see how things “really work” under the hood. In practice, this is an ongoing iterative exercise.
