# Definition 
**Mutual Reflection** is the process by which two systems emulate and/or modify each other’s behavior. 

It is equivalent to simultaneously [pivoting](<Op pivot>) a system $S_1$ by $S_2$ and the reverse, then (optionally) modifying each system by its pivot.

**Holoreflection** is the generalization of mutual reflection, where an element *a* in system *S* reflects all other elements in *S*.
